`characters/refs/katie.png` — we feed them back as reference images so every
future video keeps the SAME face (character consistency).

### Tip for perfect consistency
1. Generate #1 and #2, pick the best face for each.
2. In Gemini, upload that image + say: "keep this exact character, now show Katie
   cooking a tiny meal in the kitchen" etc. This locks the face across all scenes.
3. Recreate the activity scenes from the reference sheet (cooking, fishing,
   shopping, travel, laptop day, cleaning, diary reading) using the same refs.
